1 Systemanforderungen

  • ✓
    macOS 13.0 (Ventura) oder neuer
  • ✓
    Apple Silicon (M1, M2, M3, M4) - Intel wird nicht unterstützt
  • ✓
    OBS Studio 33.0 oder neuer
⚠️
Wichtig: Dieses Plugin funktioniert nur auf Apple Silicon Macs (M1/M2/M3/M4). Intel-basierte Macs werden nicht unterstützt, da das Apple Vision Framework dort keine GPU-Beschleunigung bietet.

2 Installation

Option A: Automatische Installation

Öffne Terminal und führe folgenden Befehl aus:

cd "/pfad/zum/plugin" ./install.sh

Option B: Manuelle Installation

  1. Plugin-Ordner finden

    Navigiere zum OBS Plugins-Verzeichnis:

    ~/Library/Application Support/obs-studio/plugins/

    Tipp: Drücke Cmd + Shift + G im Finder und füge den Pfad ein.

  2. Plugin kopieren

    Kopiere den gesamten Ordner vision-background-removal.plugin in das plugins-Verzeichnis.

  3. OBS neu starten

    Beende OBS Studio vollständig und starte es neu.

💡
Falls der plugins-Ordner nicht existiert, erstelle ihn einfach.

3 Filter hinzufügen

  1. Quelle auswählen

    Rechtsklicke auf deine Video-Aufnahmequelle (Webcam) in OBS.

  2. Filter öffnen

    Wähle "Filter" aus dem Kontextmenü.

  3. Effektfilter hinzufügen

    Klicke auf das + unter "Effektfilter" und wähle "Vision Background Removal".

  4. Einstellungen anpassen

    Konfiguriere den Filter nach deinen Wünschen (siehe Einstellungen unten).

5 Tipps für beste Ergebnisse

  • 💡
    Gute Beleuchtung: Eine gleichmäßige Beleuchtung von vorne verbessert die Erkennung erheblich.
  • 📏
    Abstand zum Hintergrund: Mehr Abstand = bessere Trennung von Person und Hintergrund.
  • 👕
    Kontrastierende Kleidung: Vermeide Kleidung, die der Hintergrundfarbe ähnelt.
  • 🎥
    Niedrigere Auflösung: Falls Performance-Probleme auftreten, reduziere die Webcam-Auflösung auf 720p.

6 Fehlerbehebung

Plugin erscheint nicht in OBS

Stelle sicher, dass der Plugin-Ordner korrekt strukturiert ist:

vision-background-removal.plugin/ └── Contents/ ├── Info.plist ├── MacOS/ │ └── vision-background-removal └── Resources/ └── locale/ ├── en-US.ini └── de-DE.ini

OBS stürzt ab beim Laden

Dies passiert, wenn du eine Intel-Version von OBS auf Apple Silicon nutzt (Rosetta). Lade die native Apple Silicon Version von OBS herunter.

Hohe CPU/GPU-Auslastung

Wechsle zur Qualitätseinstellung "Schnell" oder reduziere die Webcam-Auflösung. Die GPU-Nutzung ist normal - das Plugin nutzt die Neural Engine deines M-Chips.

Für Entwickler: Selbst kompilieren

Wenn du das Plugin selbst kompilieren möchtest:
